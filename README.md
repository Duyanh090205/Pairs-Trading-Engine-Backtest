# Quant Finance Program - Pairs Trading Engine & Backtest

This repository contains the complete progression of my Quantitative Finance program, spanning from Week 0 through Week 6. It chronicles the development of an institutional-grade pairs trading strategy, including data ingestion, signal generation, statistical arbitrage validation, and a microstructure-aware backtesting engine.

## Directory Structure

* **Week 0 - Week 3:** Exploratory data analysis, statistical tests (Cointegration, ADF), and base strategy formulation.
* **Week 4:** Core strategy implementation, Kalman Filter integration, and walk-forward validation.
* **Week 5:** The "Friction" phase. Microstructure-aware backtesting, empirical bid-ask spreads, slippage modeling, and the Net-of-Fees Performance Report.
* **Week 6:** Live execution and paper trading pipeline implementation.

*(Note: Large raw datasets and cache files are excluded from version control via `.gitignore` to maintain repository speed and health).*
